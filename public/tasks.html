Live import from Excel on SharePoint

Same Power Automate pattern as Jobs. Build a scheduled flow that POSTs rows from your Excel table into the webhook below.

1. Get your webhook credentials

2. Map your Excel columns

3. Build the flow in Power Automate

  1. Scheduled cloud flow → Recurrence every 10 min.
  2. Excel Online (Business) → List rows present in a table, pointed at your SharePoint file.
  3. HTTP POST to the Webhook URL with headers apikey: <anon key>, Content-Type: application/json, and body: 
    {
  "p_api_key": "<Temporium API key>",
  "p_rows": @{body('List_rows_present_in_a_table')?['value']}
}
