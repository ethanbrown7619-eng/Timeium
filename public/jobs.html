Live import from Excel on SharePoint

Temporium exposes a webhook that Power Automate can POST rows to on a schedule. Set it up once in Microsoft Flow and the jobs table stays in sync every 10 minutes — no local agent, no Azure app registration.

1. Get your webhook credentials

These are org-specific. Keep them private — anyone with both values can write to your jobs table. Rotate the key if it leaks.

2. Map your Excel columns

Enter the exact column names from your sheet. In Power Automate, "List rows present in a table" returns each row with the header text as keys — these must match.

3. Build the flow in Power Automate

  1. Open make.powerautomate.com → Create → Scheduled cloud flow. Set recurrence to 10 minutes.
  2. Add step: Excel Online (Business) → List rows present in a table. Point it at your SharePoint file and pick the table.
  3. Add step: HTTP → method POST, URI = the Webhook URL above.
    Headers: 
    apikey: <Supabase anon key>
Content-Type: application/json
    Body: 
    {
  "p_api_key": "<Temporium API key>",
  "p_rows": @{body('List_rows_present_in_a_table')?['value']}
}
  4. Save & test. Rows appear under View all with source webhook and a live Last synced timestamp.
